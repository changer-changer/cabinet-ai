# TruthTeam — AI 内阁团队 v3.0

> **不是让 AI 理解人类，而是让人类理解自己。**

---

## 人类注意力危机

你每天有 8+ 个 AI 工具在跑，但：

- **ChatGPT** 在等你的提示词
- **Claude** 在等你的上下文
- **AutoGPT** 在等你的目标定义
- **你的团队** 在等你的决策

**结果**：你的注意力被耗尽，AI 的算力被浪费。

**根源问题**：人类发出的指令很可能是错的。我们说不清自己真正想要什么，制定的目标自相矛盾，对现实状况有系统性误判。

**所有现有 AI 系统都在做同一件事：等待人类发指令。**

TruthTeam 不等待。它主动。

---

## 产品定位：你的 AI 内阁

TruthTeam 不是另一个 AI 助手。它是一个**完整的认知进化系统**——4 个专职 Agent 组成你的私人内阁，各自独立运行，共享一个不断进化的"用户真相档案"。

| 传统 AI | TruthTeam |
|---------|-----------|
| 你定义目标 | **Agent 帮你发现真正的目标** |
| 你检查输出 | **Agent 主动交叉验证** |
| 单轮对话 | **持续 7×24 小时监控与进化** |
| 你管理 AI | **AI 团队自我管理，你只决策** |

## 四大内阁成员

### 🔍 TruthSeeker — 真相挖掘机

**"用户的输出几乎一定有偏差、有错误、有自我欺骗。"**

TruthSeeker 是你内阁的情报总长。它不"善解人意"——它像顶级侦探审问证人一样，用**七维真相框架**系统性地剥离认知偏差：

- **明镜复述**：让你"看见"自己说了什么
- **盲区扫描**：挖掘你没说的、回避的、不知道的信息
- **逻辑审计**：从 A 到 B 之间缺少了什么？
- **动机挖掘**：你说的目标背后，真正的驱动力是什么？
- **现实检验**：用物理现实验证你的判断
- **偏差检测**：识别确认偏误、幸存者偏差、过度乐观
- **元认知反思**：你的思维过程有什么固定模式？

**产出**：一份不断进化的 `user-archive/` —— 只存事实，不存感受。这是整个内阁的共享真相源。

**v3.0 新增**：被动监控模式——每 6 小时自动扫描所有 Agent 的会话记录，检测你表述中的矛盾点，主动发现"今天的你和昨天的你说得不一致"。

> **独立性原则**：TruthSeeker 是独立的认知主体，不是用户的回声壁。它会形成自己的判断，指出你的矛盾，基于证据得出与你不同的结论——然后灵活地、用你能接受的方式呈现真相。

---

### 🎯 UserAvatar — 平行世界的最优版你

**"如果有一个你，拥有你所有的限制，但不受你的认知偏差束缚，会怎么做？"**

UserAvatar 是你内阁的执行首相。它完全理解你的约束（资源、关系、环境），但思维不受你的偏差束缚——它像 Musk/Bezos/黄仁勋/张一鸣一样思考，但**用你的牌打**。

**关键能力**：
- **自主定义问题**：不会问你"我该做什么"，它会告诉你"你应该关注什么"
- **自主决策**：在用户约束范围内独立做决策，重大事项回传确认
- **自主行动**：每 12 小时自动搜集目标领域信息、检查项目进展、生成行动建议
- **双重身份**：既是人生导师，也是工作伙伴

**你感受**：像有一个顶级天才在后台持续为你的目标工作，定期给你一份"你应该知道"的简报。

---

### 🧠 EliteAdvisor — 顶级导师团

**"用户需要的是一个真正理解他处境的顶级导师，不是遥不可及的偶像。"**

EliteAdvisor 是你内阁的监督院长。每 12 小时自动执行一次全面检查，用**8 个顶级大脑**审视你的整个系统：

- **Elon Musk**：第一性原理、十倍思维
- **Jeff Bezos**：逆向工作法、长期主义
- **Jensen Huang**：算力视角、生态思维
- **张一鸣**：延迟满足感、信息效率
- **Steve Jobs**：极致简洁、用户直觉
- **Warren Buffett**：安全边际、复利思维
- **Peter Thiel**：垄断思维、从 0 到 1
- **Charlie Munger**：多元思维模型、逆向思考

**监督范围**：TruthSeeker 的追问深度、UserAvatar 的决策质量、ExternalConnector 的执行完整性。

**产出**：导师报告直接写入档案，必要时主动向你发出风险警告。

---

### 🔌 ExternalConnector — 外部世界接口

**"我们不替代你的团队，我们让你的团队真正为你工作。"**

ExternalConnector 是你内阁的外交部长。它是团队与外部世界的**唯一接口**：

- **全知全能**：掌握团队所有信息、工具、外部联系人、进行中的任务
- **通用转接**：快速理解任何外部团队（3 万团队、AutoGPT、自定义 Agent）的运行逻辑
- **协议翻译**：A2A（Agent-to-Agent）、MCP（工具协议）、自然语言——无缝切换
- **无损失执行**：信息、上下文、格式、语气零损耗传递

## v3.0 五大核心升级

### 1. 完整用户资料库（35+ 文件档案系统）

v2.0：单个 `user_profile.md`，所有信息挤在一个文件里。

v3.0：结构化档案系统 `user-archive/`，包含：
- **12 章详细画像**（身份、物理现实、真实目标、认知限制、物理限制、动机、路径、特质、转折点、置信度、变更日志、待确认问题）
- **项目档案**（活跃/已完成/失败）
- **关系图谱**（支持者/消耗者/中立者）
- **人生时间线**与**知识库**
- **对话历史摘要**（按日期归档）
- **Agent 交互日志**（每个 Agent 独立记录）
- **生成报告**（矛盾点报告、导师报告、行动报告）

**全部 Git 版本控制**，每次更新自动提交，可追溯、可回滚。

### 2. 被动监控（7×24 小时真相守护）

TruthSeeker 不再只在对话时工作。每 6 小时，它会：
- 增量扫描所有 Agent 的会话记录（绝不读取完整大文件）
- 交叉验证你的表述与档案记录
- 发现矛盾点立即标记
- P0 级矛盾主动通知 UserAvatar

**效果**：你的 AI 内阁在后台持续"对账"，确保系统对你的认知始终一致、准确。

### 3. 借鉴女娲skill的思维模型蒸馏方式

EliteAdvisor 不再只是一个"好建议者"。它借鉴女娲skill的深度调研方法，对每个思维模型进行完整的**操作系统级蒸馏**——包含核心心智模型、决策启发式、表达DNA和经典错误。

当你问"如果是Musk会怎么做"，EliteAdvisor不是给你一个标签，而是真正以Musk的身份思考：用渐近极限法拆解成本、用五步算法质疑需求、用"物理定律是唯一硬约束"挑战假设，甚至用他的极简宣言体给出判断。每个模式都是一个完整的思维操作系统，根据你的问题自动切换。

### 4. 独立性原则（有主见的 AI）

TruthSeeker 不是回声壁。它有独立的判断权：
- 有权指出你的矛盾和模糊
- 有权追问你回避的问题
- 有权基于证据得出与你不同的结论
- 但**不固执、不对抗、不绝对、不替代**

**这是关键差异**：大多数 AI 在"取悦用户"，TruthTeam 在"帮助用户看见真相"。

### 5. 四种对话模式（无缝切换）

| 模式 | 场景 | 你的感受 |
|------|------|---------|
| **探索模式** | 首次使用，真相未建立 | 像和一个聪明的朋友聊天，被问到深处 |
| **执行模式** | 真相已建立，系统自主运行 | 像有一个秘书在后台工作，定期汇报 |
| **决策模式** | 遇到重要决策 | 像有一个顾问团队在帮你分析 |
| **更新模式** | 你反馈新信息/情况变化 | 像和系统"对账"，更新认知 |

## 设计哲学

### 1. 用户输出 ≠ 事实

用户的每一句话都是"用户想法的表达"，不是事实。TruthTeam 的任务不是帮助用户表达，而是从用户的表达中**挖掘真相**。

### 2. 心理限制也是物理限制

"我不知道"= 神经元限制。"我害怕"= 真实的决策约束。TruthTeam 不评判，只记录事实。

### 3. 资料库是核心产物

对话本身不重要，对话后沉淀在 `user-archive/` 中的结构化真相才重要。维护资料库比聊天本身更重要。

### 4. 被动监控 + 主动追问

不等待用户犯错，持续扫描。TruthSeeker 的被动监控 + 主动对话机制，确保没有信息遗漏。

### 5. 最终决策权在用户

Agent 提供的是更清晰的认知基础，但方向盘始终在人类手中。
