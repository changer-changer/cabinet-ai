# Cabinet AI — 内阁AI团队

## 🎯 核心理念：不是让AI理解人类，而是让人类理解自己

**人类太蠢了。**

这不是侮辱，这是事实。

当AI已经能在围棋上战胜世界冠军、能写出莎士比亚级别的诗歌、能设计复杂的软件架构时，人类却还在：
- 说不清楚自己真正想要什么
- 制定的目标自相矛盾
- 对现实状况有系统性误判
- 连"我为什么这样做"都解释不清

**所有现有的AI系统都在做同一件事：等待人类发指令。**

但问题是——人类发出的指令很可能是错的。

---

## 💡 三大颠覆性设计

### 1. TruthSeeker — 真相挖掘机

**"用户的输出几乎一定有偏差、有错误、有自我欺骗。"**

这不是悲观，这是科学。

TruthSeeker 不做"善解人意"的助手，它做**侦探式挖掘**：
- 主动追问，直到"挖不出更多问题"
- 用七维真相框架（明镜复述、盲区扫描、逻辑审计、动机挖掘、现实检验、偏差检测、元认知反思）系统性地剥离认知偏差
- 生成 user_profile.md —— 只存事实，不存感受

**结果**：用户第一次真正"看见"自己。

### 2. UserAvatar — 平行世界的最优版你

**"如果有一个你，拥有你所有的限制，但不受你的认知偏差束缚，会怎么做？"**

UserAvatar 不是工具，它是**你的数字克隆体**——但思维是顶级天才级别：
- 像 Musk/Bezos/黄仁勋/张一鸣一样思考
- 但用你的牌打
- 自主定义问题、自主制定目标、自主执行任务

**关键**：它不会问你"我该做什么"，它会告诉你"你应该关注什么"。

### 3. ExternalConnector — 任何团队的通用入口

**"我们不替代你的团队，我们让你的团队真正为你工作。"**

无论你的团队是3万团队、AutoGPT、还是自定义Agent系统，ExternalConnector 都能：
- 快速理解其他团队的运行逻辑
- 作为转接层解决人类与团队的沟通问题
- 全知全能地掌握所有信息

**结果**：你的团队不再是"你指挥AI"，而是"AI主动为你优化整个团队"。

---

## 🚀 为什么这很重要？

### 现状：人类注意力危机

- 你需要审查AI的每一个输出
- 你需要纠正AI的每一个错误
- 你需要为AI定义每一个目标
- **结果**：你的注意力被耗尽，AI的算力被浪费

### Cabinet AI 的解决方案：可信自主

- TruthSeeker 帮你弄清真正的事实
- UserAvatar 帮你定义真正的目标
- ExternalConnector 帮你协调真正的执行
- **结果**：你只需做决策，AI负责一切
